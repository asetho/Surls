Built for your links

Everything behind a short URL

Run Surls with Docker Compose and PostgreSQL. Your public homepage can stay built in or use files from your own webroot.

↗

Links with control

Use generated or custom aliases. Edit destinations, add tags and notes, set expiration or click limits, and disable or archive links.

▥

Useful click insights

See totals, recent activity, referrers, devices, and locations. Privacy opt-out requests skip detailed click records.

▣

Share beyond the URL

Upload files behind short links, show QR codes, copy and share URLs, and export click statistics as CSV.

⌁

Tools for your workflow

Use API tokens, a bookmarklet, CSV import, a link checker, and a UTM builder. Create links from WordPress with the included plugin.

◇

Sign-in choices

Secure local accounts with passkeys, TOTP, and backup codes. Connect supported external identity providers when you need them.

◈

Make it yours

Switch light, dark, or system theme; tune the admin palette; and add your own public pages or login template.
