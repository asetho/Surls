# Security Policy

## Reporting a vulnerability

If you believe you found a security vulnerability in Surls, visit the
[repository advisories page](https://github.com/asetho/Surls/security/advisories)
and select **Report a vulnerability**. This sends the report privately to the
maintainers. Please avoid posting vulnerability details in a public issue or
pull request while the report is being investigated.

Include the affected version or commit, steps to reproduce, the potential
impact, and any known workaround. Remove real credentials, personal data, and
production records from examples before submitting them.
