# Responsive matrix

For all linked baseline cells, main content loaded and `document.documentElement.scrollWidth` equaled the viewport width. This does not establish that every inner control fits: the two `F` cells identify content clipping/wrapping. `—` means no capture, not a pass. Dark mode was also captured at 390×844 and 1440×900 for all twelve baseline routes (see [route matrix](route-matrix.md)).

## Findings

- **F01, high:** Dashboard top-link Share button wraps almost vertically at 768×1024; text/action geometry breaks without page overflow. [dashboard__768x1024__light__default.jpg](screenshots/dashboard__768x1024__light__default.jpg).
- **F03, medium:** Link management at 1024×768 squeezes destination names and URLs to fragments; heading and count also wrap awkwardly. [links__1024x768__light__default.jpg](screenshots/links__1024x768__light__default.jpg).
